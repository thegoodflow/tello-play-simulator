📱 CONNECT YOUR MOBILE APP

1. Same Wi-Fi Network: Make sure your mobile phone and this PC are connected to the same Wi-Fi router / network (or phone Wi-Fi hotspot).

2. Enter Drone IP in Your App: In your mobile app's connection or IP setting, enter one of your computer's local Wi-Fi IP addresses below:

Control Port (UDP): 8889 Sends commands (command, takeoff, rc, etc.)
Telemetry Port (UDP): 8890 Receives real-time drone state (10Hz)
Video Port (UDP): 11111 H.264 video feed when streamon is called

💡 The simulator accepts all standard Tello SDK text commands, including joystick rc a b c d packets and autonomous flight steps.
